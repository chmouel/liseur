按你的方式阅读 EPUB：边听朗读边跟随文字，随读随译，或询问人物和事件。Liseur 将手机、OPDS 目录、calibre-web、Komga、BookOrbit 和 liseur-sync 中的图书汇集到同一书库。

朗读

朗读任意 EPUB，逐句高亮并自动翻页。如果安装了兼容的离线语音，Android 语音也可以离线朗读。按语言选择声音、调整语速、熄屏后继续收听，或设置睡眠定时器。也可连接兼容 OpenAI 的语音服务器，包括你自己网络中的服务器。

翻译

翻译选中文段，或逐页阅读其他语言的译文。Liseur 会将译句保存在手机上，返回页面时即可继续阅读。你可以使用 Android 设备上的系统翻译器，或使用自己网络中或在线托管的 OpenAI 兼容翻译服务。可用目标语言朗读译文，也能留在当前页面查词。

阅读伴侣

向阅读伴侣询问人物和事件。人物档案会参考所选文字之前的内容，包括前面的章节和当前章节中更早的段落；来源摘录会显示信息出处。你也可以为每本书开启后台章节摘要。可使用 OpenAI 兼容服务。

即使没有 AI 服务，阅读伴侣也会在设备上建立可搜索的人物、地点和群体索引，并显示哪些名字在之前的章节中共同出现。它只识别首字母大写的名称，因此不会索引中文文本。无需 API 密钥。

阅读体验

选择分页或连续滚动，调整字体、页边距和亮度，并使用浅色、羊皮纸、深色或纯黑主题。添加高亮、笔记和书签，搜索全文，并在弹窗中查看脚注。可导入自己的字体，也可使用内置字体和出版方字体。墨水屏模式会关闭动画，并支持在 Onyx 设备上控制刷新。

书库与同步

浏览本地文件夹和 SD 卡，将图书整理成系列，或在内置的 Project Gutenberg 目录中查找免费图书。桌面小组件可显示正在阅读的书或封面书架。可将设置、字体、阅读位置和批注备份为 ZIP 文件。

通过 calibre-web、Komga、BookOrbit 或 liseur-sync 同步阅读位置。任何 OPDS 目录都可以连接到 KOReader 同步服务器。使用 liseur-sync 还可按设备备份设置，并在多台设备间查看阅读统计。

隐私

没有广告。阅读保存在设备上的图书无需账号。Android 系统翻译器和阅读伴侣的本地索引会在手机上处理书籍文本。选择在线翻译、阅读伴侣或语音服务时，Liseur 会将文本发送给你选定的服务商。可选的词典查询会连接 Wiktionary；浏览目录时会连接 Project Gutenberg。
