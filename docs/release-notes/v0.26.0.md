This release gives you more control over text selection and dictionary lookups, with more reliable backup exports. It also improves sync messages and the tools available while reading.

### Reading

- Customize the selection toolbar: reorder, hide, restyle and relabel actions, or add website searches. Built-in options include Wikipedia, Open Library, Ask Brave and Duck.ai; custom searches can use book and position details. You can also move actions with accessibility controls. ([#398](https://github.com/chmouel/liseur/pull/398))

- Turn on dictionary lookup on long-press to open a definition for a word. Keep your finger down and drag across up to six words to look up a short phrase; longer selections show the usual toolbar. You can also select text from the definition sheet, and the first lookup after changing chapters works as expected. The setting is now at the end of the Dictionary group. ### Library

- Sync notices now distinguish between an account that is not set up and a sync with nothing to do. Manual sync results use the app's current language. ([#398](https://github.com/chmouel/liseur/pull/398))

### Fixes

- Backup exports are prepared before the save screen opens, avoiding empty ZIP files when an export fails or is interrupted. Cancelling or leaving the screen also cleans up prepared copies. ([#396](https://github.com/chmouel/liseur/pull/396))
- Starting a new note near an existing highlight no longer reuses that note's text or colour. ([#395](https://github.com/chmouel/liseur/pull/395))
- Website searches use the language of the selected text, including on translated pages. The `{isbn}` placeholder now accepts only valid ISBNs. ([#398](https://github.com/chmouel/liseur/pull/398))
