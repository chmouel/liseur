This release makes EPUB progress syncing with KOReader more reliable and keeps large-library quote scans from exhausting memory.

### Reading
- When syncing EPUB progress to KOReader, Liseur now sends an exact position when it can, so KOReader can reopen at the passage you were reading. Positions are handled safely around long chapters, CDATA, non-UTF-8 text, and tabs; when an exact position can’t be measured reliably, Liseur falls back to the percentage. ([#562](https://github.com/chmouel/liseur/pull/562))

### Library
- Scanning large books for Home quotes now processes sentences a paragraph at a time, reducing memory use and avoiding crashes.
