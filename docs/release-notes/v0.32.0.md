This release makes it easier to shape how your books look, keep track of notes and saved words, and pick up listening where you left off. You can also correct book details without losing your reading history or edits during supported server sync.

### Reading
- Add anki words and passages to your vocabulary collection while reading, then review them offline. ([#501](https://github.com/chmouel/liseur/pull/510))
- Set side margins more precisely and adjust top and bottom margins independently. ([#500](https://github.com/chmouel/liseur/pull/500))
- Read more comfortably on foldables and larger screens, dim the display below the system minimum, and use smoother page turns and read-aloud media controls. ([#504](https://github.com/chmouel/liseur/pull/504), [#506](https://github.com/chmouel/liseur/pull/506))
- Read aloud from a page, skip by chapter, cancel while it prepares, and return to a paused session from the library. Voice errors stay visible until resolved. ([#498](https://github.com/chmouel/liseur/pull/498))

### Library
- Edit a book’s title, author, description, series, volume and cover from its details. Edits survive rescans, are included in backups, and sync to servers that support metadata edits. ([#518](https://github.com/chmouel/liseur/pull/518), [#519](https://github.com/chmouel/liseur/pull/519))
- Browse highlights and notes from all your books in one place. Search, filter, group by book or recency, and open or edit an entry. ([#512](https://github.com/chmouel/liseur/pull/512))

### Fixes
- Catalog downloads that return web pages are no longer saved as EPUBs; when a single download fails this way, you can open the page in a browser. Unavailable catalogs offer a retry. ([#511](https://github.com/chmouel/liseur/pull/511))
- Adding books, fonts, folders, dictionaries or backups no longer crashes on devices without a file picker; Liseur tells you when none is available. ([#497](https://github.com/chmouel/liseur/pull/497))
- Fixed a library sorting crash on some older Android versions. ([#508](https://github.com/chmouel/liseur/pull/508))
